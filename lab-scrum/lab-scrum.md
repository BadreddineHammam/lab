01 · THE CONTEXT

# A clear start for the team

### The need
Agree on what the Art Gallery website should do.

### The challenge
Turn project needs into clear, ordered work.

### Our objective
Prepare the team and its first plan before development.

This phase is about organizing the work—not presenting a finished website.

---

02 · THE FRAMEWORK

# Scrum makes work visible

Scrum is an Agile framework for organizing work in steps and helping a team make progress together.

1. **Set priorities** — Product Backlog
2. **Do the work** — Team collaboration
3. **Share progress** — Daily Stand-up
4. **Adjust together** — Resolve blockers

**In this lab:** Use Scrum practices to prepare the Art Gallery project for development.

---

03 · TEAM ROLES

# Everyone has a clear responsibility

### Product Owner — decides what matters
- Understand client needs
- Define features
- Set priorities

### Scrum Master — helps the team work
- Organize Scrum meetings
- Support Scrum practices
- Help remove obstacles


---
### Developers — build the product
- Develop website features
- Coordinate tasks
- Share progress and blockers

The lab team has four students: one Product Owner, one Scrum Master and two Developers.

04 · PROJECT SCOPE

# What will the website include?

| Feature | Purpose |
|:--|:--|
| **Homepage** | Introduce the art gallery |
| **Gallery** | Display different artworks |

**Product Owner’s task:** Clarify what the client expects before the team starts building.

05 · PRODUCT BACKLOG

# Order the work by priority

The Product Backlog is the ordered list of work needed for the project.

---
| Priority | Task |
|:--|:--|
| **HIGH** | Analyze requirements |
| **HIGH** | Create project structure |
| **HIGH** | Design the homepage |
| **HIGH** | Develop the gallery page |
| **MEDIUM** | Add artwork images |
| **MEDIUM** | Create contact page |
| **MEDIUM** | Create admin section |
| **LOW** | Test the website |

Use the list to see what matters first.

---

06 · DAILY STAND-UP

# Three questions. One shared picture.

1. **What did I do?** — Share progress since the last meeting.
2. **What will I do next?** — Make today’s focus clear.
3. **What is blocking me?** — Ask for help with problems early.

**Goal:** Share progress, coordinate work and help one another.

---

| Team member | Yesterday | Today | Blocker |

09 · TAKEAWAYS

# Plan clearly. Communicate often.

- **Product Owner:** Clarifies needs and priorities.
- **Scrum Master:** Supports the team and its process.
- **Product Backlog:** Shows what work comes first.
- **Daily Stand-up:** Shares progress and blockers.

**A well-organized team has a clearer path into its technical project.**
