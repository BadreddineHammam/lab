# Building an Art Gallery Website

Planning and organizing a web project

**Presented by:** Badreddine Hammam

<!-- _class: dark -->

01 · INTRODUCTION

# A Website Needs a Clear Plan

Before development, the team must know:

- **What?** Define the goal and website features.
- **Who?** Assign roles and responsibilities.
- **When?** Plan the work.
- **How?** Track progress and manage risks.

**Objective:** Prepare a clear work plan for an Art Gallery website.

---

02 · THE PROJECT

# What Are We Building?

A website that introduces an art gallery and presents its artworks.

| The website helps visitors… |
|:--|
| Learn about the gallery |
| Browse artworks |
| View artwork details |
| Contact the gallery |

**Key question:** What should visitors be able to do?

---

03 · THE PROJECT SCOPE

# Define the Website Boundaries

| Included in the project | Out of scope |
|:--|:--|
| Homepage and gallery introduction | Online artwork purchases |
| Artwork gallery and details | Online payment |
| Contact page | Delivery service |
| Admin login and artwork management | Mobile application |

A clear scope helps the team focus on the agreed website.

---

04 · THE STAKEHOLDERS

# Who Participates in the Project?

- **Product Owner** — represents the gallery's needs.
- **Scrum Master** — organizes the team and facilitates its work.
- **Developers** — design and build the website.
- **Gallery representative** — explains the content and expectations.

---

05 · RESPONSIBILITIES

# Who Does What?

| Role | Responsibility |
|:--|:--|
| Product Owner | Define visitor and gallery needs |
| Scrum Master | Organize the team and help solve problems |
| Developer 1 | Build the backend and manage artwork data |
| Developer 2 | Build the pages and visitor interface |

Clear responsibilities make collaboration easier.

---

06 · WORK ORGANIZATION

# Divide the Website into Tasks

**Main features**

1. Homepage and gallery introduction
2. Artwork gallery and detail pages
3. Contact page and admin tools

**Example: artwork management**

- Add an artwork
- Display artwork in the gallery
- Update artwork information
- Remove an artwork

Smaller tasks are easier to assign and track.

---

07 · PLANNING

# Schedule the Work

| Week | Planned work |
|:--|:--|
| 1 | Gather requirements and plan the website |
| 2 | Create the project structure and homepage |
| 3 | Build the gallery and artwork detail pages |
| 4 | Add contact and artwork administration |
| 5 | Test the website and fix issues |

**Estimated duration: 5 weeks**

---

08 · RESOURCES

# What Do We Need?

| Resource | Estimate |
|:--|:--|
| People | 3 developers |
| Tools | VS Code, Git and GitHub |
| Technologies | PHP, JavaScript, HTML, CSS, MySQL |
| Content | Artwork images and descriptions |
| Time | 5 weeks |

---

09 · RISKS

# Anticipate Problems

| Risk | Prevention |
|:--|:--|
| Artwork images or details are missing | Confirm content needs early |
| Database problems | Test changes and make regular backups |
| A task takes longer than planned | Review progress and keep extra time |
| Code is lost | Use Git and GitHub regularly |

---

10 · MONITORING

# Make Progress Visible

During the daily meeting, everyone shares:

1. What was completed?
2. What will I work on today?
3. Do I have a problem or blocker?

| To do | In progress | Done |
|:--|:--|:--|
| Create the contact page | Build the gallery page | Set up the database |
| Add artwork details |  | Create the homepage |

---

11 · DELIVERABLES

# What Results Must We Deliver?

- Website requirements
- Database structure for artwork information
- Art Gallery website source code
- Working pages for browsing and viewing artworks
- Artwork administration tools
- Technical documentation and final presentation

---

12 · KEY TAKEAWAYS

# The Basics of a Well-Organized Project

- **Goal:** Present the gallery and its artworks.
- **Scope:** Agree on included pages and features.
- **Team:** Assign roles and responsibilities.
- **Plan:** Divide the website into tasks and schedule them.
- **Monitoring:** Check progress and manage risks.
- **Deliverables:** Know what website and documents to provide.

---

13 · CONCLUSION

# Organize to Build a Better Website

- Clarify what visitors and the gallery need.
- Agree on the website scope.
- Organize people, tasks and time.
- Anticipate risks and follow progress.
- Test and deliver a working Art Gallery website.

**A clear plan helps the team turn the gallery's needs into a website.**
