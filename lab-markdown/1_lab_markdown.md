# Art Gallery Management System
---
## 1. Project Subject

My project is an **Art Gallery Management System**.

It is an application that helps manage an art gallery. It stores information about artists, artworks, and art mediums.
---
## 2. Project Objective

The objective of this project is to organize and manage art gallery information easily.

Users can:
- Manage artists.
- Manage artworks.
- Organize art mediums.
